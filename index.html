Testing an AI assistant

Python, Inception framework, prompt engineering

Problem
An AI assistant had to give correct, consistent answers across media commands, web questions and smart-device actions, in both UI and API layers.
My role
Owned test design, test data and automation for response validation, and managed defects through the full test cycle.
Approach
Wrote test scenarios for each query type and automated response checks in Python. Evaluated tool and function-call behavior: whether the right tool was picked, whether parameters were extracted correctly, and whether multi-step reasoning held up. Refined prompts to close gaps, then ran root cause analysis, debugging and retesting. I fixed several defects directly.
Result
Raised application stability to above 90% by making tests more reliable and cutting flaky cases.

API testing for connected smart-home devices

Kotlin, Swift, EarlGrey, Bazel

Problem
Many device types integrated with a smart-home app, and their APIs needed checking on both Android and iOS.
My role
Wrote and ran API tests, and traced failures to their source.
Approach
Added new automated test methods in Kotlin and Swift, used EarlGrey for UI and integration tests, and used Bazel for build and test workflows. Used SDK knowledge to separate product defects from infrastructure issues.

Test results dashboard

SQL, MySQL

Problem
Test progress was reported by hand, and clients could not easily see coverage, pass rate or why tests failed.
My role
Designed and built the dashboard end to end.
Approach
Wrote SQL queries, joins and views to show total, automated and blocked test counts, execution trends over time, and the overall pass rate. Added failure reasons next to each failing test.
Result
Clients can now see coverage and pass rate on their own, and the team triages failing tests faster.
